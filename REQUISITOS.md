# Requisitos

## Objetivo

Conseguir vaga de **analista de dados com machine learning**, usando este repositório como portfólio público e o LinkedIn como vitrine.

## Escopo (por enquanto)

- Foco em **análise de dados + ML clássico** (SQL, estatística, Python/pandas, Power BI, scikit-learn, séries temporais).
- Fora do foco agora: deep learning, NLP avançado e LLMs. Podem virar uma fase 2 depois que os 4 projetos estiverem publicados.

## Entregas

1. 4 projetos de portfólio, um por mês, com temas de **RH e suporte de TI** (a área que já conheço de perto).
2. Cada projeto com README de vitrine: problema, dados, método, resultado e próximos passos.
3. 1 post por semana no LinkedIn, alternando "o que aprendi" e "o que construí".

## Regras

- **Só dados públicos ou sintéticos.** Nunca subir dado real da empresa nem dado pessoal (LGPD). Se um tema vier do trabalho, recriar com dados gerados.
- Cada dataset tem **fonte e licença** anotadas no README do projeto.
- Repositório público: nada de senha, token ou caminho interno de rede.
